# Cybort Metrics

So far, Cybort collects "items."

I'd like Cybort to collect "metrics" as well.

When we create our presenters later (HTML dashboards, etc) I'd like to show aggregate measures over time.

Example metrics:

- Apple Health data (will need to be synced by iOS/iPad device w/ access to Apple Health)
- Temperature readings and other readings from IoT devices in my home
- Github activity (commits, reviews, etc) per hour/day
- Air quality readings from public APIs
- To-Do items completed (will sync to Notion or similar)
- Reddit posts/replies made by me per day
- Hacker News posts/replies made by me per day
